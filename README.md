1. 이 질문은 회귀·군집·연관 가운데 무엇으로 풉니까? 왜 그렇습니까?
   회귀로 푸는게 적합할것같다. 이유는 주제가 원인과 결과간의 인과관계와 영향력을 수치적으로 파악해야하는 문제이기 때문에
2. 이 질문에 답하려면 데이터의 어느 열이 필요합니까?
   종속변수, 독립변수, 통제변수(결과, 원인, 환경)
3. 이 데이터는 누가, 언제, 무엇을 위해 만들었습니까? 사용해도 되는 데이터입니까?
   한국공항공사(KAC)와 국토교통부, 그리고 미국 교통부 통계국(BTS)이 항공 운항 데이터이고 현재 진행형 데이터이고 승객 권익 보호를 위해 만들어졌고 사용해도됨.
4. 처음 찾은 데이터 후보는 무엇이었고, 왜 바꾸거나 남겼습니까?
   처음 찾은 데이터가 내가 찾는 데이터였어서 처음 찾은 데이터가 첫 후보였고 바꾼적이없다. 남긴이유는 출처와 다양한 데이터를 원했던만큼 찾아줘서 남겼다.
5. AI가 추천한 주제나 데이터 가운데 버린 것은 무엇이고, 이유는 무엇입니까?
   버린 주제가 없다.
